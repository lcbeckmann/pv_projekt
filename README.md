# PV-Modellierung, Projektgeruest

VU Kontinuierliche Simulation 325.118.

- `doku/Projektvorgehen.pdf` zuerst lesen. Steht drin, wer was macht und nach
  welchen Regeln gearbeitet wird.
- `doku/annahmen.md` ist das Entscheidungslog. Jede Vereinfachung landet hier,
  sofort und nicht am Schluss.
- `matlab/` enthaelt das lauffaehige Geruest. Details in `matlab/README.md`.
- `latex/` ist das Protokollgeruest fuer Overleaf. Details in `latex/README.md`.

## Overleaf einrichten

Den Ordner `latex/` als ZIP hochladen (New Project, Upload Project).
Die Abbildungen aus `matlab/figures/` muessen dann zusaetzlich nach
`abbildungen/` in Overleaf, oder ihr bindet Overleaf per Git an ein Repo,
das beides enthaelt.
